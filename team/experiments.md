## 已知残留问题（提分方向）

- 剩余 3 个 miss 的意图卡全是泛化约束（"cotton"+"Imported" 类），预算未进卡——判别信号不足，需要 profile 软偏好（M4）兜住尾部。（实验 6b 后 Recall@100 已 1.000，miss 全是排序层问题）
- MRR 0.669 是当前最大提升空间（权重 0.30）：命中轮的目标排名还不够靠前 → M3 的交叉编码器/LLM 精排的主战场。
- 稠密路 v1 已上（实验 6b）：非置换并集保证"捞全"。~~route_scores（dense_sim 进排序）~~ **已用诊断实验证伪**（实验 7：打平局里目标 sim 名次中位 81，稠密与指纹信号同源）——不再推进，MRR 长尾归 M3。
- **给 C 的明确挑战（实验 4b）**：LLM 精排目前是负收益，USE_LLM 默认保持 0。要让它转正，方向有三：
  ① prompt 里带上命中证据（哪条约束命中了哪个候选），别只给标题；
  ② 只在规则低置信时调用（top-1 无约束命中 / 分数打平时做 tie-break），别全量重排；
  ③ 或者改用 LLM 做约束解析/查询改写而非排序（面向私有集句式变体的鲁棒性，这才是规则解析器最脆的地方）。
