## 给 C：可选接入（`actionable_rejections`，预期收益小但零风险）

`ranker.py::rank()` 里，在排序前过滤掉信号里判定"确实卡住了"的候选：

```python
from src.memory import signals   # 新增 import

def rank(state: DialogState, candidates: list[dict], k: int = 10) -> list[dict]:
    if not candidates:
        return []
    dead = signals.actionable_rejections(state.session_id)
    if dead:
        live = [c for c in candidates if c["parent_asin"] not in dead]
        if len(live) >= max(k, 10):          # 不够就不过滤，镜像 retriever.py budget 过滤的写法
            candidates = live
    total = max(len(candidates), 1)
    ...  # 其余不变
```

诚实预期管理：HitRate 已经 0.99，多数 session 命中太早、根本来不及积累到 `stagnant_turns>=2` 就已经结束，所以这条**大概率影响面很小**（诊断口径下 408 次逐轮比较里只有 5 次真正变化）。是否值得占用你 C-T2/C-T4 的时间由你判断，不强求；`signals.py` 已有单测覆盖，接入本身风险极低。
