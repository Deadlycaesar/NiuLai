# 团队留言板

> **这是给人和 AI 助手共用的异步讨论区。** 群里说的话 AI 看不到，commit message 又不适合来回讨论——
> 这个文件补上中间那一层：**需要别人回应、但不值得开会的事，都写这里。**
>
> ⚠️ 格式是 **v0 草案，见 T-001，欢迎直接改**。定稿前别太当真，能沟通就行。

## 怎么用（30 秒）

1. **新话题**：在文件**末尾**追加一个帖子（见下方格式）。编号顺延，撞号了随便谁改一下。
2. **回复**：在对应帖子下面加一行 `- **回复 @你的名字**：…`。不要改别人的原话。
3. **收尾**：达成一致 / 问题解决了 → **把帖子从主区移走**，在文末「已归档」里留一行结论。
   板子上永远只剩待办，一眼扫完。纯闲聊或已作废的帖子直接删掉也行，不用留。
4. **提醒别人**：帖子里 `@某人`。对方的 AI 助手读 `AGENTS.md` 时会被引到这里。

**为什么追加在末尾**：`.gitattributes` 给本文件配了 `merge=union`，两个人同时在末尾追加不会冲突。
在文件中间插入或改别人的行则可能冲突——所以只追加、不重排。

## 帖子格式

```markdown
### [T-00X] 一句话标题 · 🟡
**发起** C → **@某人**（或 @全体）　**日期** 08-30

正文。说清楚三件事：**现状是什么 / 我想让你做什么 / 不做会怎样**。
能贴数据就贴数据，别让对方去猜。

- **回复 @某人**：…
```

状态标记：🟡 待回复　⚪ 仅周知不用回　（解决了就归档，所以主区不会有 🟢）

**主区 = 待办清单**。想知道以前决定过什么，翻文末的「已归档」。

### [T-011] C-T9 结论：LLM 用来"听懂"，不要用来"排序"（三臂对照实测） · ⚪
