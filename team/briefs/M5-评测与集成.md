# M5 · 评测 / 实验 / 集成 + PM（负责人：E · 待认领）

> 把本文件 + 根目录 `AGENTS.md` 一起喂给你的 AI 编码助手。**你是唯一允许在 `scripts/`、`tests/`、CI 层面动全局的人。**

## 职责

让"任何人任何改动 10 分钟内知道分数变化"，并守住所有工程红线。

1. **评测流水线**：包装官方评测器——全量 200 条（合龙时跑）+ 抽样 50 条脚本（PR 触发，注意抽样要按四场景分层，否则方差大到没法比较）；分数自动追加进 `team/experiments.md`（日期/分支/改动摘要/总分/四场景分项/token 花费）。
2. **消融开关**：统一的配置层（环境变量或 config.py）：`USE_LLM`、`USE_DENSE`、`USE_RERANKER`、`ASK_POLICY=naive|entropy` 等，每个模块可独立开关——这是 Day 3 写报告时所有对照实验的基础。
3. **CI 冒烟**：GitHub Actions——每个 PR 跑 5 个 session 保证不崩 + 密钥扫描（防 key 入库）+ 校验 `evaluator/` 与 `data/public_set.jsonl` 无 diff + 校验 `starter/agent.py` 仍是转发壳。
4. **仓库与节奏**：main 保护、PR review、每日 12:30/17:00 合龙、分数回退 >0.02 追责定位。
5. **交付打包**：提交前转公开、README 复现步骤、干净环境一条命令演练、Devpost 填报、token/延迟/成本披露汇总（从 C 的 usage 统计聚合）。

## 边界

- ✅ 做：脚本、CI、配置层、实验记录、打包、进度主持。
- ❌ 不做：业务模块实现；**绝不改 `evaluator/`**（你的包装只允许 import 官方模块或起子进程，红线中的红线）。
